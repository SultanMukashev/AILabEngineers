# Car Price Prediction API 

FastAPI-приложение для оценки стоимости автомобиля по характеристикам.

---

##  Описание выполнения Третьего Задания (Third Task)

**Цель:** Построить полный ML-пайплайн от данных до API + Docker-контейнеризацию.

### Выполненные пункты:

1. **Использование данных**
   - Использован заскрапленный датасет автомобилей с ```kolesa.kz```.
   - Проведена начальная очистка и анализ данных.

2. **ETL-процесс**
   - Разделено на модули: `extract.py`, `transform.py`, `load.py`.
   - Имитирован процесс получения raw данных, их предобработки и загрузки.

3. **Разделение данных**
   - Данные разбиты на train/test/validation.
   - Оставлена часть данных для последующего retrain модели.

4. **Обучение модели**
   - Использован `RandomForestRegressor` для предсказания стоимости.
   - Сохранение модели через `joblib`.

5. **Разработка приложения (FastAPI)**
   - Эндпоинты `/predict`, `/retrain`, форма на `/`.
   - Возможность дообучения модели на новых данных через `/retrain`.

6. **Контейнеризация через Docker**
   - Создан оптимизированный `Dockerfile`.
   - Убран лишний мусор, настроена работа только через необходимые зависимости.

7. **Оптимизация образа**
   - Минимизирован размер образа за счёт Slim-базы и удаления кешей.

8. **(Дополнительно)**
   - Проработана структура кода, соблюдена модульность и читаемость.
   - Готов проект для возможной интеграции GitHub Actions и Kubernetes.

---

## 📦 Функционал

- Оценка стоимости автомобиля через API `/predict`
- Веб-форма для обычных пользователей (`/`)
- Возможность дообучения модели через API `/retrain`
- Полная контейнеризация через Docker

---

##  Собрать и запустить контейнер

```bash
docker build -t car-price-api .
docker run --rm -p 8000:8000 car-price-api
```

Приложение будет доступно по адресу:

```
http://localhost:8000
```

## 🖥️ Структура проекта

| Путь | Назначение |
|------|------------|
| `main.py` | Эндпоинты FastAPI |
| `models.py` | Валидация данных Pydantic |
| `inference.py` | Загрузка и дообучение модели |
| `train.py` | Скрипт начального обучения модели |
| `templates/` | HTML-шаблоны |
| `requirements.txt` | Зависимости |
| `model/` | Файл с моделью (в гите не хранится) |
| `etl/` | Модули ETL процесса: extract, transform, load |
